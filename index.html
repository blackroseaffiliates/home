NC IT Weekly Board

A single responsive page for your classmates. The timetable is shown at the top, and the announcements section is below it. That way, when you share the link, people can immediately see the weekly learning schedule, what is due, what has already been done, and any extra notices you post.

How updates work You edit the content directly in the code and push the changes to GitHub Pages. No website login or admin dashboard is required.
Built for Phones, laptops, desktops, and tablets. The layout scales automatically and keeps the content readable.

Editing tip

The timetable and announcements are stored in two JavaScript arrays inside index.html. Change the text there, commit, and push. Your classmates then refresh the page and see the newest version.
